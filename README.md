### 作者：姜玄衣

#
# 使用说明
##### 响马卦排盘插件
1. 下载xiangmagua的压缩包
2. 放到vault的/.obsidian/plugins目录中解压为文件夹
3. 进入obs，启用社区插件
4. 启动插件，设置快捷键
5. 原神启动
